# 🏋️ RawFitness

**Discipline Lives Here**

RawFitness is a mobile-first Gym Management and Fitness Tracking web application designed to help gym members manage their workouts, attendance, streaks, memberships, payments, and fitness progress from one place.

---

## 📌 Project Overview

RawFitness provides a simple and modern interface for gym members to track their daily fitness activities.

The application is currently under development. The frontend is being built using HTML and CSS, with JavaScript and backend integration planned for upcoming versions.

---

## ✨ Features

- User Login & Signup
- Home Dashboard
- Workout Tracking
- Attendance Tracking
- Workout / Attendance Streaks

- Membership Management

- Membership Renewal & Payments

---

## 📱 Main Pages

### Login
Allows registered gym members to securely access their RawFitness account.

### Home Dashboard
Displays important fitness information including:

- Current streak
- Total workouts
- Attendance percentage
- Fitness goals
- Total weight lifted
- Next workout
- Daily motivation

### Workout
Users can view their workout plans, exercises, sets, reps and weights.

### Attendance
Tracks gym attendance and calculates attendance percentage and streaks.

### Membership
Displays:

- Current membership plan
- Membership status
- Start date
- Expiry date
- Renewal option

### Profile
Allows users to view and manage their personal and fitness information.

## 📄 Software Requirements

The major functional requirements of RawFitness include:

1. Users should be able to register and log in.
2. Users should be able to track workouts.
3. The system should maintain attendance records.
4. The system should calculate workout/attendance streaks.
5. Users should be able to view their membership status.
6. Users should be notified before membership expiry.
7. Users should be able to renew their membership.
8. Users should be able to manage their profile.
9. Administrators should be able to manage members, attendance and memberships.
